# Open Electronic Classroom

开源电子教室 —— 面向中小学机房与平板教室的课堂管理软件。

> **状态：重构中。** 仓库已清空重来，旧版本（Qt 桌面壳 + 静态网页原型）不再保留在版本历史中，仅以全新起点重新设计。

## 计划中的组成

| 模块 | 说明 | 状态 |
| --- | --- | --- |
| `Teacher/` | 教师端控制台：设备名单、屏幕/视频/白板共享、文件分发、课堂策略 | 待实现 |
| `Student/` | 学生端：接收画面、提交作业、遵守课堂策略 | 待实现 |
| `Docs/` | 架构、协议与设计文档 | 待实现 |

## 目标能力

- 局域网内的设备发现与在线状态
- 教师屏幕 / 窗口 / 白板实时共享，支持多路学生画面回传
- 文件与作业分发、随堂答题与收卷
- 课堂网络策略（URL 白名单、USB 传输、外网访问限制）
- 教师端与学生端跨 Windows / Android / iPadOS 的可用性

## 开发约定

- 语言与框架选型在架构文档定稿后统一，不提前引入
- 提交信息遵循 Conventional Commits（`feat:` / `fix:` / `chore:` …）
- 构建产物、依赖目录、临时截图一律不进仓库
